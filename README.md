## Project Overview
MechaMinds developed an autonomous self-driving robot for the WRO Future Engineers challenge.  
The robot is designed to navigate a structured environment using computer vision, sensor fusion, and real-time control systems.

The system enables the robot to follow lanes, detect colored pillars, and avoid obstacles autonomously.

---

## Main Features
- Real-time lane detection using camera vision  
- Detection of red and green pillars  
- Obstacle detection and emergency stop system  
- Autonomous navigation and decision-making  
- Sensor fusion for stable movement  

---

## Hardware
- Raspberry Pi 5 (main controller)  
- Camera Module 3 Wide (120° field of view)  
- HC-SR04 ultrasonic sensor  
- MPU-6050 IMU sensor  
- TB6612FNG motor driver  
- 4WD aluminium chassis  
- 3S LiPo battery (11.1V / 2200mAh)  

---

## Software
- Python  
- OpenCV (computer vision)  
- NumPy (data processing)  
- GPIO libraries for hardware control  

---

## How It Works
The robot processes live camera input to detect lanes and navigation markers.  
Sensor data from ultrasonic and IMU modules is combined to ensure safe and stable navigation.  
The system continuously adjusts motor speed and direction in real time.
